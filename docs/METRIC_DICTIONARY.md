# 交易中台核心指标标准字典 (METRIC_DICTIONARY)

> 本字典定义了交易中台经营分析涉及的全部标准化指标体系。
> 统一计算口径，避免跨团队协同中出现“同名不同义”或“同义不同名”的口径壁垒。

---

## 一、 订单全链路漏斗转化指标

| 指标名称 | 英文标识 | 计算公式 | 统计口径说明 | 业务观察含义与判定导向 |
| :--- | :--- | :--- | :--- | :--- |
| **冒泡数** | Bubbles | $\sum \text{估价请求}$ | 用户在客户端确认起止点并成功返回价格与预估履约时效的次数 | 衡量用户下单需求的原始意向基数 |
| **呼叫数** | Calls | $\sum \text{发单请求}$ | 用户确认发单并进入派单等待池的订单次数 | 衡量实际进入撮合池的有效需求规模 |
| **冒发率** | Bubble-to-Call Rate | $\frac{\text{呼叫数}}{\text{冒泡数}}$ | 价格和预估时间向发单行为的转化率 | 反映用户对预估定价和时效的满意度，低于基准线需关注 |
| **举手数** | Responses | $\sum \text{供给响应次数}$ | 在线供给端接收到派单意向并成功反馈响应的次数 | 衡量供给端对当前订单池的接单热度 |
| **举手率** | Response Rate | $\frac{\text{举手数}}{\text{呼叫数}}$ | 呼叫订单中被至少一位合规供给方响应的比例 | 反映供给充沛度（受供给在线率、基础定价、环境路况等影响） |
| **给单数** | Dispatches | $\sum \text{成功派发订单}$ | 中央派单算法判定最优并将订单派发给供给方的订单数 | 衡量系统完成供需撮合动作的订单数 |
| **给单率** | Dispatch Rate | $\frac{\text{给单数}}{\text{举手数}}$ | 供给方响应订单中最终由平台确认派发的比例 | 反映算法撮合效率与供给竞争格局（若过低，说明大量响应落空或时空错配） |
| **完单数** | Completes | $\sum \text{正常完成订单}$ | 供给方完成履约并由系统确认交付结算的订单数 | 最终履约成功的业务规模核心指标 |
| **完单率** | Completion Rate | $\frac{\text{完单数}}{\text{给单数}}$ | 成功派发后最终完成交付履约的比例 | 反映履约交付韧性 |
| **取消数** | Cancels | $\sum \text{取消订单}$ | 接单后因用户取消、供给方取消或系统超时关闭的订单 | 履约流失的直接负向指标 |
| **取消率** | Cancellation Rate | $\frac{\text{取消数}}{\text{给单数}}$ | 派单成功后因各种原因流失的比例 | 高于警戒阈值需重点排查长距离匹配与供给方协商取消 |

## 二、 规模与财务产出指标

| 指标名称 | 计算公式 | 统计口径说明 | 业务决策导向 |
| :--- | :--- | :--- | :--- |
| **GMV (交易总额)** | $\sum \text{用户应付订单金额}$ | 包含起步基准价、时长/里程费、动态加价（不扣减券） | 衡量平台促成的整体交易经济规模 |
| **平台流水 (Turnover)** | $\sum (\text{供给方应收} + \text{平台抽佣})$ | 扣除跨平台外部通道费后的真实结算流水 | 财务核算与分账基数 |
| **客单价 (AOV)** | $\frac{\text{总 GMV}}{\text{总完单数}}$ | 平均每张完成订单贡献的交易额 | 衡量订单结构质地（长短单结构是客单价的核心拉动力） |
| **抽佣率 (Take Rate)** | $\frac{\text{平台抽佣总额}}{\text{总 GMV}}$ | 扣除供给端分成后平台截留的佣金比例 | 衡量平台的商业化变现能力 |
| **单均运营利润** | $\frac{\text{平台净利润}}{\text{总完单数}}$ | 扣除渠道分成、补贴、税费后的单均净利 | 衡量经营健康度的底线指标 |

## 三、 结构划分标准

### 1. 订单区间划分（长短单）
- **短单**：
  - 起步短程区间：高频、短时履约场景居多；
  - 中短程区间：日常高频需求，频次高。
- **长单**：
  - 中远程区间：跨区中长途履约；
  - 远程大单区间：跨区域高峰长途履约；
  - 特殊远单区间：综合枢纽接驳、跨城长距履约，客单价高，含返程调度溢价。

### 2. 渠道与产品线定义
- **渠道分类**：
  - **自营渠道**：自建客户端与服务号直接触达用户，具有高数据沉淀与客群留存价值；
  - **聚合渠道**：主流生活服务与综合聚合平台流量中枢导入，规模大但需遵循聚合竞价派单协议。
- **产品线分类**：
  - **基础型**：主力走量品类，兼顾价格与服务标准；
  - **特惠型**：低价一口价模式，平峰引流，单均分成偏低；
  - **品质型**：高履约标准、高评价供给专享，客单价具备合理溢价。
